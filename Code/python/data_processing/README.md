# Data Processing

Directory Name: data_processing
Creation Date: 2023-03-15
Author: Didem Dost

## Objective

Handles data loading, preprocessing, and transformation for model training and evaluation.

## Structure

- **data_loader.py**: Functions to load embeddings and labels
- **data_preprocessing_target.py**: Preprocessing for target classification
- **data_preprocessing_type.py**: Preprocessing for exotoxin type classification
- **folds_data_loader.py**: Data loading for cross-validation
- **tests/**: Unit tests for data processing functions
