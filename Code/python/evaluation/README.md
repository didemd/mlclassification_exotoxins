# Evaluation

Directory Name: evaluation
Creation Date: 2023-03-15
Author: Didem Dost

## Objective

Provides tools for model evaluation, metrics calculation, and performance visualization.

## Structure

- **confusion_matrix_plot.py**: Functions to generate and plot confusion matrices
- **curves.py**: ROC, precision-recall, and learning curve generation
- **metrics.py**: Calculation of evaluation metrics (MCC, accuracy, precision, recall)
- **tests/**: Unit tests for evaluation functions
