
This section presents two predictors, ExoType and ExoTarget, which differentiate bacterial exotoxin types and targets based on different inputs, including protein sequences and protein folds. We first describe the data exploration and preprocessing steps, then outline the feature analysis, and finally discuss the model training and evaluation results.

\section{Redundancy Reduction}

This step was applied to ensure models ability to generalize unseen data.

First, MMseqs2 tool was used to set the similarity threshold to 100\% in order to get rid of duplicates, if there are any. After that , 30\% similarity was applied reduced the count from 2,492 to 1,068. This reduction reduces sequence similarity among dataset, allowing us to focus on the unique characteristics and functional diversity of exotoxins.

As shown in Table~\ref{tab:merged_dataset_distribution}, after eliminating redundant sequences, the over-representation of Type III exotoxins remains even less pronounced (the percentage of Type III drops from 86\% to 74\%).

The redundancy reduction further limited the already scarce data, which increases the likelihood of the model memorizing it and overfitting. This, in turn, increases the necessity for dimensionality reduction later in the project pipeline. The drop in data imbalance will likely reduce bias toward the majority class in the final model. While reducing redundancy improves model generalizability, it further limits the available data, increasing the risk of overfitting.

\section{ExoType Predictor}
This section describes the development of the ExoType predictor, which classifies exotoxins into five categories: Type I, Type II, Type III, Type IV, and Unknown. The following subsections outline the training and evaluation of the model using two different data representations:

1. Sequence-based embeddings (generated from protein sequences using MMseqs2)
2. Fold-based embeddings (derived from protein structures predicted by AlphaFold2)

\subsection{Model Training}
Five models with different architectures were trained to predict different exotoxin types: Logistic Regression, Support Vector Machines, K-Nearest Neighbours, Hierarchical Model, and Random Forest. 

\begin{itemize}
	\item Logistic Regression,
	\item Support Vector Machines,
	\item K-Nearest Neighbours,
	\item Random Forest,
	\item Hierarchical Model
\end{itemize}

To evaluate performance, we applied two data-splitting strategies:

\subsubsection{Approach 1: Standard Train-Test Split}

The dataset of 1,067 embeddings was divided into:
\begin{itemize}
	\item 80\% training set (848 samples)
	\item 20\% test set (213 samples)
\end{itemize}

Class distribution in the training set:
\begin{itemize}
	\item \textbf{Type I}: 10
	\item \textbf{Type II}: 77
	\item \textbf{Type III}: 699
	\item \textbf{Type IV}: 14
	\item \textbf{Unknown}: 48
\end{itemize}

\subsubsection{Approach 2: Redundancy Reduction Based Split}

The dataset of 1,067 embeddings was divided into:
\begin{itemize}
	\item \textbf{Type I}: 12
	\item \textbf{Type II}: 96
	\item \textbf{Type III}: 875
	\item \textbf{Type IV}: 18
	\item \textbf{Unknown}: 60
\end{itemize}

Comparing the two approaches reveals several key differences. In the original split, the training set consisted of 848 samples with relatively fewer samples for the minority classes, whereas the redundancy reduction approach yielded a training set with slightly higher counts for these classes, yet the overall distribution remained heavily skewed toward Type III. 

In Figure~\ref{fig:import_test_learning_curves_type} In terms of cross-validation MCC, the original approach achieved values of 0.62, 0.62, 0.63, and 0.74 for Random Forest, Logistic Regression, SVM, and KNN respectively. These changes mean that while the redundancy reduction approach has improved the performance of some models, due to the increasing of the minority classes, the overall impact is similar. The class imbalance in the second approach may limit the models' ability to generalize better, indicating that while there is a hint of improvement, additional strategies to further address the imbalance might be necessary to prevent the potential underfitting of the minority classes.

Moreover, although the validation MCC scores for all models improve with more data, SVM and Logistic Regression appear more balanced between fitting the training data and generalizing well. This pattern indicates that SVM and Logistic Regression are more suitable for the classification of toxin types using sequence-based embeddings.
